🤖 IA permitida
Podés utilizar IA para generar el formulario.
👤 Intervención humana
Después deberás:
cambiar los nombres de los campos;
agregar un campo nuevo;
cambiar el tipo de uno de los campos;
agregar placeholder;
agregar required a dos campos.

🧠 Preguntas
Explicá:
for="nombre"
y:
id="nombre"
¿Qué relación tienen?


--> RESPUESTA: El atributo for e id deben ser iguales para que se vincule el texto con el campo. 


🔧 Error para encontrar
Corregí este código:
<label for="nombre">
    Nombre
</label>

<input
    type="text"
    id="apellido"
>
Explicá qué estaba mal.


--> RESPUESTA: El atributo for es distinto del atributo id, por lo tanto no quedarian vinculados. 


🗣️ Defensa oral
El profesor puede preguntarte:
¿Qué pasa si cambio el id del input pero no cambio el for del label?


--> RESPUESTA: El label con el input, no quedarian vinculados.
