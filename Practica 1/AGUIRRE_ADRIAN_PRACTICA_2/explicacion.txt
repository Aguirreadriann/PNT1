🧠 Preguntas
¿Cuál es la diferencia entre <ul> y <ol>?
¿Para qué sirve <li>?
¿Qué diferencia existe entre <strong> y <em>?

-> RESPUESTA 1: La diferencia es que la etiqueta <ul> genera listas desordenadas y la
etiqueta <ol> genera listas ordenadas.

-> RESPUESTA 2: La etiqueta <li> sirve para representar cada elemento de la lista.

-> RESPUESTA 3: La etiqueta <strong> sirve para poner el texto en negrita y darle importancia
al texto. La etiqueta <em> sirve para poner el texto en italica y hacer enfasis en una parte 
del texto.


🔧 Cambio sorpresa
El cliente informa que el orden de las películas no importa, pero el orden de las actividades sí.
¿Qué lista debería utilizarse en cada caso?
Explicá tu decisión.

-> RESPUESTA: Utilice la etiqueta <ul> para generar la lista de peliculas ya que su orden no
importa, ya que solo lo marca con puntos, y utilice la etiqueta <ol> para generar la lista
de las actividades preferidas ya que el cliente necesitaba un orden y estas se generan con
numeración en orden ascendente.
