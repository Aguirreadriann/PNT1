🧠 Explicación
Entregar debajo del formulario:
Utilicé <label> para relacionar el texto con el campo y el usuario conozca que dato hay que
ingresar.

Utilicé <input type="email"> porque valida que el texto ingresado tenga formato de correo.

Utilicé radio para que el usuario seleccione una sola modalidad en lugar de dos al mismo tiempo.

Utilicé checkbox para que el usuario tenga multiples elecciones de conocimientos.

Utilicé select para que el usuario pueda seleccionar un curso sin la necesidad de ocupar toda la
pantalla.

Utilicé textarea para que el usuario pueda escribir un mensaje o comentario largo antes de
inscribirse.
