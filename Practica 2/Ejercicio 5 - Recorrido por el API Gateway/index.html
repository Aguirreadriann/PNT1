Recorrido de la solicitud

  1. El usuario completa el formulario.
  2. JavaScript obtiene los datos.
  3. Se construye un objeto JavaScript.
  4. El objeto puede convertirse a JSON.
  5. Se prepara una petición HTTP.
  6. La solicitud llega al API Gateway.
  7. El Gateway determina el servicio.
  8. El backend procesa la solicitud.
  9. El backend genera una respuesta.
  10. El frontend muestra el resultado.
